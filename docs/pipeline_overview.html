The eight steps

pancolon_pipeline.py <step>
Stage 1 · Tissue → Phenotypesenv: pancolon_tiling · TensorFlow
1
tileDeepPATH

Tile each whole-slide image into 224 px patches at 20× magnification, dropping background.

.svs / .ndpi / .tif→tile pyramid
2
to_hdf5DeepPATH

Pack the tiles into a single HDF5 tile store in HPL's expected format.

tiles/→hdf5_<cohort>_he_complete.h5
3
projectHPL

Project every tile through the trained HPL BarlowTwins_3 self-supervised encoder to get 128-dim embeddings.

tile HDF5→img_z_latent embeddings
4
cluster_filterHPL

Assign each tile to the shipped reference Leiden clustering — the histomorphological phenotype clusters (HPCs).

embeddings→per-tile HPC labels
5
assign_hpcbuilt-in

Drop artifact clusters (pen marks, blur, folds) and write the filtered per-tile HPC table plus a per-slide manifest.

HPC labels→filtered table + manifest
Stage 2 · Phenotypes → Prognosisenv: pancolon_survclam · PyTorch
6
build_ptSurvCLAM

Convert the filtered HPL embeddings into a per-slide .pt feature store for the survival model.

embeddings h5→pt_files/*.pt
7
infer_survivalSurvCLAM

Score every slide against all 16 leave-one-institution-out fold checkpoints; the CHiPS score is the mean per-fold risk.

.pt store→chips_scores.csv
8
attention_mapSurvCLAM

Extract per-tile attention and render H&E overlays annotated with each slide's CHiPS score.

.pt + tile coords→attention overlays

Trained weights

scripts/download_weights.sh

HPL encoder BarlowTwins_3

Self-supervised tile encoder trained on the pan-colon cohort at 20×. Powers step 3.

Reference HPC clustering

The fixed Leiden clustering + folds that new tiles are assigned against in steps 4–5.

SurvCLAM CHiPS folds

16-fold imaging-only DFS survival model (no clinical covariates required). Drives steps 7–8.

🔬
Imaging-only. CHiPS is computed from histology alone, so collaborators can score slides with no clinical or outcome data. Providing an optional labels CSV additionally yields a C-index and Kaplan–Meier curves.

Running it

one config drives everything

Local · single GPU box

# create the two envs once
conda env create -f envs/env_tiling.yml
conda env create -f envs/env_survclam.yml

# configure, then run all 8 steps
bash scripts/run_local.sh config/pipeline.yaml

SLURM · dependency chain

# submits 8 jobs, each afterok the last
bash scripts/slurm/submit_all.sh config/pipeline.yaml

# preview commands without running
python pancolon_pipeline.py all \
  --config config/pipeline.yaml \
  --dry-run --no-env-switch

What you get

under paths.work_dir/

survclam/chips_scores.csv

The headline result — one row per patient.

  • chips_score — mean risk across folds
  • chips_percentile — cohort-relative rank
  • chips_tertile — low / intermediate / high

attention/

Per-slide attention tensors and rendered overlays.

  • chips_overlays.png — H&E, attention heatmap, and HPC panels titled with the CHiPS score
  • Rendered by notebooks/attention_overlay.ipynb

PanColon-CHiPS-Pipeline — vendors DeepPATH, Histomorphological-Phenotype-Learning (HPL), and SurvCLAM. Inference only; trained weights ship separately. CHiPS = Computational Histological Prognostic Score.
